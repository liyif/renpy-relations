# 每轮1000～10000个条件

这次扩大的是**每轮实际读取的不同派生条件数**，默认1000／3000／10000个，不是只扩大规则库存或重复查询少数条件。每个领域有两层共享前置关系，另计64个派生关系。每个领域内各条件使用不同模数的数值条件，结合领域状态、全局开关和否定条件，产生混合真假结果。

## 实测结果

实测从2026-10-13 23:30至2026-10-14 00:18（Asia/Singapore）。72种配置各三次独立重复，**216次全部成功**；1080个计时轮次共执行并核对**5,040,000次条件读取**。相同输入摘要、SDK驱动、源码摘要、各轮请求数及cached重建计数的一致性检查通过。

Ryzen 9 7900X，Ren’Py 8.5.3内置Python 3.12.8、pysqlite3／SQLite 3.51.1、SQLAlchemy 2.0.43。以下取当前SQL依赖图版本、cached模式、领域状态分表、事实数:总派生关系数约1:10的三次独立试验中位数；时间为**整轮**，不是单次has。

| 每轮条件 | 事实 | 首轮（秒） | 重复轮（秒） | 单次读取中位数（微秒） | 局部修改后重建数 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1000 | 107 | 0.501 | 0.258 | 200.8 | 34 |
| 3000 | 307 | 1.664 | 0.811 | 198.3 | 96 |
| 10000 | 1007 | 6.697 | 3.560 | 209.4 | 315 |

万条件时，约1:1配比下cached重复轮为3.700秒，约1:10配比为3.560秒；事实数减少近10倍，整轮仍在秒级。按依赖失效减少重建，不会减少本次有意要求执行的10000次独立查询。

同为万条件、cached模式、1:1配比，“局部提交＋整轮读取”先在每次试验内相加再取中位数：领域分表时旧版6.101秒／新版3.864秒；通用状态表时旧版5.900秒／新版6.988秒。共享事实表导致广泛失效，额外依赖管理可能使新版更慢，不能将局部收益泛化到所有布局。

整轮延迟直接测量，不能用单次中位数乘条件数替代；较慢调用、调用循环和自动GC等都会影响总量。每组只有三次独立重复，不提供生产尾延迟或跨硬件保证。当前接口每个条件分别执行has和查询事务；下一轮值得对照批量判定接口，检验减少逐条调用能带来多少收益，本轮未同时修改运行时。

## 规模与口径

| 每轮条件 | 总派生关系 | 1:1事实数 | 约1:10事实数 |
| ---: | ---: | ---: | ---: |
| 1000 | 1064 | 1064 | 107 |
| 3000 | 3064 | 3064 | 307 |
| 10000 | 10064 | 10064 | 1007 |

每轮每个条件调用一次 `has`，以 `v0` 为查询对象；计时覆盖不同条件的独立调用。每次结果都与独立公式核对；完整行集合的初始／修改后检查在独立检查进程中完成。计时进程在加载、导入后直接执行首轮、重复轮以及局部／全局／无关修改后的读取，不插入全量校验或额外历史遍历。保留自动GC。

整轮时间包括调用、逐请求计时和轻量真假核对。单次分位数只计has调用。报告的单次p95是各独立试验p95再取中位数，不能解释为合并请求的p95。动作成本先将同一试验的提交和随后整轮读取相加，再跨试验取中位数。

原始JSON保存每个试验的阶段时间、CPU、RSS、请求数及单次min／median／p95／max，不提交大量逐请求向量。后端仍是上一版SQL依赖图实现，没有同时做运行时优化。

## 复现

```sh
uv run --locked python benchmarks/conditions.py \
  --python /path/to/renpy-sdk/lib/py3-linux-x86_64/python \
  --packages examples/palace/game/python-packages
```

默认比较三档、两比例、两布局、三模式、两后端版本，各三次独立进程，串行运行共216次。`--conditions` 控制实际读取量，`--ratios` 为1或10；其余参数可缩小矩阵。快速检查示例：

```sh
uv run --locked python benchmarks/conditions.py \
  --conditions 1000 --ratios 10 --shapes partitioned \
  --modes cached --variants native --repetitions 1
```

完整运行保留固定提交8827c21的旧版作对照；当前后端和旧版复制到`.work`独立加载，源码和fixture摘要随结果保存。输出目录必须为空。无SDK参数时使用uv Python，报告会记录实际环境。旧24条件脚本仍可复现历史实验。

本轮使用程序生成的受控SQL，不测全量Logica编译、完整Ren’Py界面、历史追踪或存档归档；失败与超时不填零、不计入成功中位数。新进程不等于清空OS页缓存后的冷启动。
