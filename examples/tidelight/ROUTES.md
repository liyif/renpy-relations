# 试玩路线（含剧透）

这些是验证可达性的示例；可以在地图中改变探索顺序，结果取决于实际取得的线索、授权与约定。

## 一条公共广播准备路线

1. 看林遥的车票，支持她出发，取得配电图。
2. 向林遥借保险，自己负责操作。
3. 听陆弥说录音上的名字，正式登记借用。
4. 把母带带回电台。随后会收到停航通知。
5. 翻电台工作簿，确认录音来源和剪辑痕迹。
6. 和陆弥看失效的船票，支持她的驻留计划；她愿意用自己的名字广播。
7. 问许澄空白后面是什么，让她选择如何被听见；取得录音授权。
8. 断电发生后，用借来的保险修复线路。

此时广播条件齐备。整条路线没有先播放许澄的“突然结束的录音”事件；那段可以留到之后。

## 五个结局

| 结局 | 一种达成方式 |
| --- | --- |
| 把空白留给明天 | 准备路线后，再陪许澄听片段，明确答应明天的约会；午夜完成自己的最终决定 |
| 抵达以后，记得来信 | 准备路线后，与林遥约定持续联系；午夜完成自己的最终决定 |
| 不为作品的一次见面 | 准备路线后，与陆弥约一次私人见面；可以把最后的声音留在屋内 |
| 一座没有屋顶的电台 | 完成广播准备，不作恋爱承诺；午夜选择公开广播 |
| 没有播出的晚安 | 没有恋爱承诺，最后选择留在屋内或安静告别；即使没有完成所有准备，也能结束故事 |

个人结局要求信任足够、对方同意并作出明确约定。广播成功并非个人结局的必要条件。朋友式回答会保留尊重，也让玩家有机会去回应另一份关系；明确作出恋爱承诺后，其他告白不再作为可选话题出现。

## 可以主动试的顺序差异

- 先陪许澄听片段、翻工作簿，再去借保险。这样可以先借保险，再看林遥的车票。
- 先在别处消磨到停航，之后见陆弥。当前最迫切的话题会先是船票，登记和声音名字稍后再谈。
- 翻过工作簿后，直接与许澄谈空白。片段谈话可以留到后面；它不会是深谈的固定前置场景。
- 先获得陆弥的借用同意，之后在她去了码头时独自回资料室取母带。十一点以后资料室关闭，这个机会就结束了。
- 擅自播放片段或取走母带，观察立即出现的传言事件，然后选择是否道歉。道歉不会自动替当事人给出后续授权。
- 只等雨、不去完成准备，也可以到达结局；午夜的公开广播选项会缺席。

每次存读档或回退，时间、行程所推导的位置、物品、同意和已发生事件一起恢复，下一批相遇也会重新计算。
